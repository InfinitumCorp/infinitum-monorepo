02 / Install

Up and running in a minute.

Neither build needs an account. Signing in to earn $VEIL is optional and kept in a separate, labeled workspace.

Android

  1. Download the APK

    Tap Download APK on your phone.

  2. Allow the install

    When Android asks, allow installs from your browser for this file.

  3. Install Orbot

    Get Orbot and turn on its VPN mode so VEIL traffic leaves through Tor.

  4. Open VEIL

    Browse. Everything is cleared when you close the app.

Chrome

  1. Download and unzip

    Save veil-extension.zip and extract it to a folder you'll keep.

  2. Open extensions

    Go to chrome://extensions and switch on Developer mode.

  3. Load unpacked

    Choose Load unpacked and select the extracted folder.

  4. Pin VEIL

    Pin it from the puzzle-piece menu and open the sidebar to pick Tor or VEIL VPN mode.
