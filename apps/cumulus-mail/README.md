# Cumulus://Mail

Private email for a Cumulus://ID. The mailbox rules live in `@infinitum/mail`. This app serves them.

```sh
node --experimental-strip-types apps/cumulus-mail/src/server.ts
```

Open http://localhost:3010. Set `XAI_API_KEY` to turn on SCALVS briefs. Set `PORT` to move the listener.
