Add @conjure to a product

  • Copy client/conjure.mjs (no dependencies) into the product's server code.
  • Set CONJURE_URL and CONJURE_PRODUCT_KEY in the product's server environment. Never ship the key to a browser.
  • Pass every message, comment or note through handleMention. It returns null when there is no @conjure.
import { conjureFromEnv } from "./conjure.mjs";
const conjure = conjureFromEnv();

const result = await conjure?.handleMention(message.text, { context: record.notes, user: user.id, source: "deal" });
if (result) await postReply(result.text);
